Research

Research Interests

I study practical security problems that emerge when powerful machine-learning models move from cloud services onto end-user devices.

01

On-Device LLM Security

Security analysis of LLMs embedded in mobile applications, including runtime behavior, deployment pipelines, and model protection.

02

Model Extraction & Reconstruction

Techniques for identifying, recovering, and reconstructing executable LLM artifacts across heterogeneous mobile inference frameworks.

03

Adversarial Machine Learning

Post-extraction attacks, behavioral replication, model safety degradation, backdoors, and other adversarial risks affecting deployed AI.

04

AI & Mobile Systems Security

Static and dynamic analysis of mobile AI systems, native runtimes, model-loading behavior, and application-level security boundaries.

Current · Dissertation Research

Security Analysis

A security-analysis pipeline for discovering on-device LLMs in real-world Android applications, recovering model artifacts, reconstructing executable models, and validating post-extraction risks. The work combines static analysis, native-code analysis, guided runtime instrumentation, and framework-aware reconstruction across multiple mobile LLM runtimes.

Downstream Security Risks of Recovered LLMs

Investigating how extraction changes the threat surface of an application-embedded model. Current experiments evaluate whether independently executable recovered models can be subjected to inference-time adversarial techniques outside the host application's controls.

Behavioral Distillation and Safety Alignment
